A tiny Python program that writes one deadpan one-star review to `/output/entry.txt`: a single line of at most 160 characters, written like a real one-star review of an everyday essential — memory, rated one star for keeping every embarrassing thing said in 2009 in perfect detail while holding a single new password for ten minutes. The line was picked by drafting fourteen candidates across gravity, sleep, the sun, water, oxygen, Mondays, memory, time and rain, and duelling them pairwise on the bounty judge's own criteria — unmistakably a deadpan one-star review of the thing itself first, then the sharpest true grievance, holding the deadpan, the turn in the last few words, and tightness. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
